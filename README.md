# Cheems API

API para la gestión de monstruos de la aplicación `django_cheems`.

## Como funciona

La API permite realizar operaciones CRUD (Crear, Leer, Actualizar, Eliminar) sobre los elementos de la aplicación `django_cheems`.

Usando la API, los usuarios pueden interactuar con los datos de la aplicación de manera programática, facilitando la integración con otras aplicaciones o servicios. Se pueden realizar solicitudes HTTP a los endpoints de la API para obtener información sobre los monstruos, crear nuevos monstruos, actualizar los existentes o eliminarlos según sea necesario.

Todo eso se facilita mediante el uso de la biblioteca Django REST Framework, que proporciona herramientas y funcionalidades para construir APIs de manera eficiente y segura. Ademas del uso de Postman para probar y documentar la API, lo que permite a los desarrolladores explorar y comprender cómo interactuar con los diferentes endpoints de la API de manera sencilla.
